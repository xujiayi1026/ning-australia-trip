# 注意宁的澳大利亚之旅 🇦🇺

像素风（星露谷画风）单文件 HTML 小游戏。零素材、零依赖，全部画面由代码绘制。

## 在线游玩

打开：**https://xujiayi1026.github.io/ning-australia-trip/**

也可以把 `index.html` 下载到本地直接双击打开。

## 玩法

- 开场动画 → 角色创建（肤色 / 眼睛 / 发型 / 发色 / 服装）
- 澳大利亚地图：目前仅 **墨尔本** 开放（弗林德斯街火车站、圣基尔达海滩、家园小岛）
- 与 NPC 对话、收集图鉴（8 件物品 / 10 种鱼），图鉴是翻开的旅行手账，带像素实物插图
- 小金鱼（你的朋友，是个人类）全程跟随，随时切换"回家 ↔ 出来玩"

## 操作

| 操作 | 电脑 | 手机 / 平板 |
| --- | --- | --- |
| 移动 | WASD / 方向键，或点击地面 | 点击地面自动走过去，拖动出摇杆连续行走 |
| 互动 / 对话 | E / 空格 / Enter | 右下角圆形「互动」按钮，或直接点击 |
| 小金鱼 | G | HUD「小金鱼」按钮 |
| 图鉴 / 地图 | I / M | HUD「图鉴 / 地图」按钮 |
| 钓鱼收线 | 按住空格 | 按住「按住收线」按钮 |
| 全屏 | HUD「⛶ 全屏」按钮 | 同左（进入全屏后铺满） |
| 音乐/音效 | HUD「♪ 音乐」按钮 | 同左 |
| 关闭面板 | Esc | 面板「关闭」/ 右下「返回」 |

- 画面自动适配窗口：手机 / 平板铺满屏幕；电脑上按窗口等比放大、最大 1280×720 居中显示（不再撑满整个大显示器），点「⛶ 全屏」可铺满
- 背景音乐为程序生成的星露谷式民谣纯音乐，进入墨尔本（落地/创建角色后）自动循环播放
- 场景音效：电车进站铃声/行驶声与画面里的电车同步、海浪拍岸、走路的脚步声，全部程序合成
- HUD 按钮带像素小图标，鼠标指针为像素箭头；右上角可一键「全屏」，画面自动等比铺满

存档自动写入浏览器 localStorage。

## 本地运行

无需构建，直接打开 `index.html` 即可。
